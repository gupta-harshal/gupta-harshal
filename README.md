## About

I'm a CS undergrad at **IIIT Ranchi** who likes shipping systems that actually move data under load — matching engines, learning platforms, and clean architecture references others can study from.

Right now I'm deep into **backend design**, **TypeScript**, and **low-level / design-pattern craft**, while keeping ML close enough to drop into real products.

**Currently focused on**
- Low-level design & GoF patterns (Java)
- Microservices, Redis, and real-time WebSockets
- Stronger TypeScript backends and system design
